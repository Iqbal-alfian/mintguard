🛡️ MintGuard

A safety auditor for BNB Chain (BSC) free mints. Paste a contract address — MintGuard reads the chain and the verified source, then returns an explainable verdict: a 0–100 score, a GO / CAUTION / BLOCK band, and the evidence behind every point. Read-only: it never asks for a signature or a wallet.

Try: a verified NFT mint · an unverified proxy · a plain wallet (EOA)

How it works: contract code + owner + supply are read over public BSC RPCs, with decisive reads confirmed on a second independent RPC. Verification comes from the Sourcify plain lookup (exact_match only counts as fully verified). When source is verified, the ABI is scanned for risky surfaces — blacklist, adjustable tax, pause control, owner mint, withdraw/rescue, mutable metadata. Unverified contracts are scored on bytecode-level signals only and say so. A score is a screening aid, not a guarantee and not financial advice.
